# Frosted — usage

## Read Order

1. `USAGE.md`
2. `DESIGN.md`
3. `tokens.css` — copy it as the project's `src/styles/tokens.css` with `widgetarium system use frosted`; change parameters, never formulas.
4. `settings.json` for the spec card.
5. `references/`, then the built examples 16–22 and `tests/`.

## Design Highlights

- At rest nothing has a background; the one chosen item is black and the only body in its row.
- Black is the primary; no hue commits anything.
- Frost: soft grey grounds, blurred plates, pills and large radii.
- Light geometric type carries size; one giant figure may lead a page.
- Lines only divide screens; tables and figure strips are spaced by air.
- Colour is information: lime good, violet needs a look, a warning is a black triangle.

## Do

- Choose `plates` by page kind: `none` for a page led by one figure, chart or table; `cards` for a set of objects opened one by one.
- Open a record over the list as a frosted plate, the list still visible behind it.
- Keep one chosen item per row of choices.

## Avoid

- A coloured primary button, colour on anything that is not information.
- A line between table rows, a border around a plate.
- Bold figures, heavy display weights.
- A wash behind a table, or more than two washed plates on a screen.
