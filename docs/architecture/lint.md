# Lint

Every rule in these pages is a folder, a file name or a type, so a tool checks it, not a review. A rule is switched on only after a count shows which files it would refuse. `node tools/lint-code.mts <roots>` runs the file rules; the engine's refusals run in `app()`; the type rules run in `npm run test:types`.

| Rule               | Refuses                                                                                                                                                                                                                   | Held by                                   |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------- |
| contracts          | a file in a domain's `requests/` that is not `<name>.query.ts` or `<name>.command.ts`; a handler class there                                                                                                              | `domain-layout` rule                      |
| request names      | a request whose name is not `<module>/<constant without suffix, kebab case>`                                                                                                                                              | `domain-layout` rule                      |
| client and server  | an import, re-export or `import()` of the domain's `server/` from `client/`, `ui/` or `lib/`                                                                                                                              | `domain-layout` rule                      |
| ui is drawn        | a file in `ui/` that is not `.tsx`                                                                                                                                                                                        | `domain-layout` rule                      |
| adapters           | a file at the top of `adapters/<what>/` that is not `.adapter.ts`; a folder under it not named for a platform or holding no `<platform>.adapter.ts`; an import of a part of `adapters/<what>/<platform>/` from outside it | `domain-layout` rule                      |
| idempotency        | a command with no `idempotencyKey`                                                                                                                                                                                        | type                                      |
| platform records   | a bare factory in `provided()`; a factory reading another platform's host                                                                                                                                                 | type                                      |
| platforms shipped  | an app naming a platform one of its dependencies has no factory for                                                                                                                                                       | type (literal module list), `app()`       |
| one handler        | two handlers for a request, two providers for a token                                                                                                                                                                     | `app()`; `send` refuses none              |
| module borders     | an injection of another module's dependency that is not exported to and imported by the asker                                                                                                                             | `app()`                                   |
| server only        | a client handler injecting a dependency provided only on `server`; an `inject()` outside a field initialiser                                                                                                              | `app()`, `inject()`                       |
| build platform     | a host of another platform than the build                                                                                                                                                                                 | `app()`                                   |
| no foreign adapter | another platform's adapter code, or `server/` code, in a bundle built from source                                                                                                                                         | build stand-ins, `test:web-canvas-bundle` |
| size               | a file over 400 lines, a function over 80 (warnings from 250 and 50)                                                                                                                                                      | `file-size`, `function-size`              |
| comments           | any comment but `TODO:` and `TRADE-OFF:`                                                                                                                                                                                  | `comments` rule, edit hook                |
| levels             | an import against the table in [README.md](README.md#imports); a package importing an app                                                                                                                                 | **planned**                               |
| public API         | an import of another package by any path but its `index.ts`                                                                                                                                                               | **planned**                               |
| declared           | an import of a domain not listed in `package.json` dependencies                                                                                                                                                           | **planned**                               |
| no cycles          | a cycle in the graph of domains                                                                                                                                                                                           | **planned**                               |
| blocks             | hand-written pointer or scroll math in a block; a decision about request data in a block                                                                                                                                  | **planned**                               |
| new in a page      | `new` of a handler or an adapter outside a module                                                                                                                                                                         | **planned** (`new` of a handler throws)   |
| index files        | anything in an `index.ts` but re-exports                                                                                                                                                                                  | **planned**                               |
| legacy             | a new file in a `legacy/` folder; an import of `legacy/` from outside its owner                                                                                                                                           | **planned**                               |

Each check is proven by breaking it on purpose: write the file it must refuse, see it red, remove the file. A rule's message says what to do, not only what is wrong.
