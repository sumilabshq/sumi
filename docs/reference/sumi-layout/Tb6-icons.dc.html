Every tab wears its own icon

A site brings its favicon, drawn as it is with nothing behind it. A Sumi app or a file type gets an icon of its own, in full colour, the way an editor gives every file type a mark and macOS gives every app one. Shown at 16, 20, 32 and 48 px, and on dark.
